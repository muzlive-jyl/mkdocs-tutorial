# MkDocs 튜토리얼

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Active-brightgreen)](https://muzlive-jyl.github.io/mkdocs-tutorial)

MkDocs를 활용한 문서 사이트 구축 튜토리얼 프로젝트입니다. 이 저장소는 MkDocs의 설치부터 배포까지 단계별로 학습할 수 있는 내용을 제공합니다.

## 📚 프로젝트 개요

이 튜토리얼은 MkDocs를 이용해 문서화 사이트를 만드는 전체 과정을 다룹니다:

- MkDocs 설치 및 기본 프로젝트 설정
- Material 테마 적용 및 커스터마이징
- 문서 구조화 및 네비게이션 설정
- 코드 하이라이팅, 확장 기능 사용법
- GitHub Pages를 통한 배포

## 🚀 시작하기

1. 저장소를 클론합니다:
   ```bash
   git clone https://github.com/muzlive-jyl/mkdocs-tutorial.git
   cd mkdocs-tutorial
   ```

2. 필요한 패키지를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```

3. 로컬에서 문서 사이트를 실행합니다:
   ```bash
   mkdocs serve
   ```

4. 웹 브라우저에서 `http://localhost:8000`으로 접속하여 사이트를 확인합니다.
